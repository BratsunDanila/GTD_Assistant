# СБРОС (Sbros) — Голосовой анти-хаос на базе GTD и ИИ

Мобильное Android-приложение на **Kotlin + Jetpack Compose (Material 3 Expressive)**, которое позволяет человеку выгружать поток мыслей голосом или текстом без какой-либо структуры, а ИИ в фоновом режиме очищает речь от эмоционального шума, деконструирует сложные задачи на микро-шаги и раскладывает всё по системе GTD.

---

## 1. Главная философия и жесткие UX-правила (CRITICAL RULES FOR AI AGENT)

При написании кода ИИ-агент **ОБЯЗАН** соблюдать следующие продуктовые ограничения:

1. **Никакого визуального давления:**
   - **ЗАПРЕЩЕНО** выводить числовые счетчики невыполненных задач на вкладках навигации, бейджах или заголовках (никаких `Полки (14)`).
   - **ЗАПРЕЩЕНО** использовать красный цвет для дат, статусы «Просрочено» (Overdue), стрик-огоньки и графики продуктивности.
2. **Невидимый GTD (Человеческий язык):**
   - Никакой корпоративной терминологии Дэвида Аллена в UI.
   - Вместо *Inbox / Next Actions / Projects / Waiting For / Someday* используем только теплые формулировки: **«Простые шаги»**, **«Большие дела»**, **«Жду от других»**, **«На потом и отдых»**.
3. **Принцип «Сказал и забыл» (Zero-Friction Capture):**
   - После окончания записи голоса или ввода текста пользователя **НЕЛЬЗЯ** принудительно перекидывать на экран проверки/редактирования карточек.
   - Шторка записи просто закрывается, парсинг уходит в фоновый воркер (`CoroutineScope` / `WorkManager`), а внизу появляется тихий `Snackbar`: *«Мысли тихо разложены по полкам»*.
4. **Защита от перегруза (Экран «Сейчас»):**
   - На главном экране никогда не отображается список задач. Отображается **ровно ОДНА карточка** под выбранное состояние энергии.
   - В разделе «Большие дела» (Проекты) наружу показывается **только первый незавершенный шаг**, остальные шаги скрыты внутри проекта, чтобы не пугать объемом работы.

## 2. Технологический стек (Android / Kotlin)

- **Язык:** Kotlin 2.0+
- **UI-фреймворк:** Jetpack Compose + **Material 3** (`androidx.compose.material3`)
- **Архитектура:** Clean Architecture (Light) + MVI / MVVM (`Single-Activity`)
- **Асинхронность:** Kotlin Coroutines + Flow (`StateFlow`, `SharedFlow`)
- **DI (Внедрение зависимостей):** Hilt (`dagger.hilt.android`)
- **Локальная БД:** Room (`androidx.room`) с поддержкой TypeConverters для списков микро-шагов
- **Хранение настроек темы:** Jetpack DataStore Preferences (`Palette`: `SAGE`, `CLAY`, `LAVENDER`, `OCEAN` + `DarkMode`)
- **Распознавание речи (STT):**
  - Базовый вариант: системный `android.speech.SpeechRecognizer` с отслеживанием пауз (Silence Detection 3 сек).
  - Продвинутый вариант: отправка аудио-чанка в Whisper API / Gemini Multimodal API.
- **Сеть и LLM API:** Ktor Client или Retrofit2 + `kotlinx.serialization` (использование **Structured Outputs / JSON Schema** для гарантированного формата ответа от LLM).

## 3. Архитектура данных (Room Database Schema)

ИИ-агент должен реализовать следующую схему хранения. Ключевая фича: каждая задача сразу хранит массив `simplifiedVariants` (3 уровня упрощения от ИИ), чтобы кнопка **«Проще»** в UI срабатывала мгновенно (за 0 мс, офлайн) без повторного запроса к серверу.

### Enums (`domain/model/Enums.kt`)

```kotlin
enum class ShelfType {
    SIMPLE_STEPS, // Простые шаги (одиночные действия)
    BIG_THINGS,   // Большие дела (проекты из нескольких шагов)
    WAITING,      // Жду от других (делегировано / ожидание)
    SOMEDAY       // На потом и отдых (идеи, фильмы, хотелки без сроков)
}

enum class EnergyLevel {
    EASY,     // Легкое (бытовуха, покупки, когда нет сил и тупишь)
    FIVE_MIN, // На 5 мин (правило 2-5 минут: быстрые звонки, сообщения)
    FOCUS     // Поработать (требует концентрации, но шаг уже раздроблен до <= 25 мин)
}
```

### Entities (`data/local/entity/Entities.kt`)

```kotlin
@Entity(tableName = "projects")
data class ProjectEntity(
    @PrimaryKey val id: String = UUID.randomUUID().toString(),
    val title: String,               // Например: "Курсовая работа"
    val createdAt: Long = System.currentTimeMillis(),
    val isArchived: Boolean = false
)

@Entity(
    tableName = "tasks",
    foreignKeys = [
        ForeignKey(
            entity = ProjectEntity::class,
            parentColumns = ["id"],
            childColumns = ["projectId"],
            onDelete = ForeignKey.CASCADE
        )
    ],
    indices = [Index("projectId"), Index("shelf"), Index("energyLevel")]
)
data class TaskEntity(
    @PrimaryKey val id: String = UUID.randomUUID().toString(),
    val projectId: String? = null,   // Если часть "Большого дела"
    val orderInProject: Int = 0,     // Порядок шага в проекте (показываем только минимальный невыполненный)
    val originalQuote: String,       // Сырая фраза пользователя ("надо сесть за курсач")
    val title: String,               // Основной конкретный шаг ("Написать черновик введения (3 абзаца)")
    val simplifiedSteps: List<String>, // 2 еще более простых варианта для кнопки "Проще"
    val currentSimplifyIndex: Int = 0, // 0 = title, 1 = simplifiedSteps[0], 2 = simplifiedSteps[1]
    val aiHint: String,              // Спокойный комментарий ИИ ("ИИ спрятал остальной курсач, чтобы он не давил")
    val categoryBadge: String,       // Короткий контекст ("Бытовое • Не требует фокуса")
    val estimatedMinutes: Int,       // Оценка времени в минутах (1, 3, 5, 20)
    val shelf: ShelfType,
    val energyLevel: EnergyLevel,
    val isCompleted: Boolean = false,
    val skippedCount: Int = 0,       // Сколько раз нажали "Не сейчас" (для мягкой амнистии)
    val lastShownAt: Long = 0L,
    val createdAt: Long = System.currentTimeMillis()
)
```

### Логика «Мягкой амнистии» в DAO/Repository:
- Если у задачи `skippedCount >= 5` или она не открывалась 14 дней, фоновый воркер тихо меняет её `shelf` на `ShelfType.SOMEDAY` без уведомлений и упреков.
- Когда пользователь нажимает **«Не сейчас»**, у текущей задачи обновляется `lastShownAt = System.currentTimeMillis()` и `skippedCount + 1`, а из базы выбирается следующая задача того же `EnergyLevel` с минимальным `lastShownAt`.

## 4. ИИ-пайплайн и системный промпт (LLM Structured Output)

Когда пользователь завершает голосовой или текстовый сброс, `DumpProcessorWorker` выполняет запрос к LLM.

### Входные данные в промпт:
1. `raw_transcript`: распознанный текст пользователя.
2. `existing_projects`: JSON-список открытых проектов из таблицы `projects` (`id`, `title`), чтобы ИИ привязывал новые мысли к старым проектам, а не плодил дубликаты.

### Системный промпт для LLM:

```text
Ты — невидимый GTD-ассистент и бережный фильтр когнитивной нагрузки в приложении «Сброс».
Твоя задача — принять сырой, хаотичный поток мыслей пользователя и превратить его в чистую структуру задач, не вызывающую тревоги.

ПРАВИЛА ОБРАБОТКИ:
1. Эмоциональный фильтр (Venting): Если пользователь жалуется на усталость, стресс или ругается ("блин, ничего не успеваю, так устал"), ОТСЕЙ это из списка задач. Не создавай задач из эмоций.
2. Принудительная конкретизация (Анти-туман): Никогда не записывай в задачи абстрактные глыбы ("Сделать диплом", "Починить камеру"). Если мысль требует больше 25 минут — создай или привяжи существующий проект (BIG_THINGS), а в саму задачу выдели ТОЛЬКО ПЕРВЫЙ ФИЗИЧЕСКИЙ ШАГ на 10-20 минут.
3. Тройное упрощение (для кнопки «Проще»): Для каждой задачи сгенерируй поле `simplified_steps` из 2 элементов:
   - Индекс 0: Упрощение задачи до действия на 2 минуты (например: "Открыть документ и написать 3 тезиса своими словами").
   - Индекс 1: Упрощение до микро-старта на 30 секунд ("Просто создать пустой файл и написать заголовок").
4. Оценка энергии (`energy_level`):
   - `FIVE_MIN`: всё, что занимает 1-5 минут (ответить в мессенджере, скинуть файл, позвонить).
   - `EASY`: бытовая рутина, не требующая мозга (заказать на маркетплейсе, зарядить батарейки, оплатить счет).
   - `FOCUS`: требует включенной головы (код, текст, учеба), но строго до 25 минут.
5. Сортировка по полкам (`shelf`):
   - `SIMPLE_STEPS`: одиночные понятные дела.
   - `BIG_THINGS`: шаг, принадлежащий крупному проекту.
   - `WAITING`: если пользователь ждет чего-то от других ("жду правки от научрука").
   - `SOMEDAY`: идеи, фильмы, книги, хотелки на выходные без обязательств.
```

### Ожидаемая JSON-схема ответа от LLM:

```json
{
  "parsed_items": [
    {
      "original_quote": "надо хотя бы за курсач сесть",
      "title": "Написать черновик введения (3 абзаца)",
      "simplified_steps": [
        "Открыть документ и набросать 3 коротких буллита: о чем работа",
        "Просто создать пустой файл и написать заголовок на первой странице"
      ],
      "ai_hint": "ИИ спрятал остальной курсач, чтобы он не давил.",
      "category_badge": "Большое дело: Курсовая",
      "estimated_minutes": 20,
      "shelf": "BIG_THINGS",
      "energy_level": "FOCUS",
      "matched_project_id": null,
      "new_project_title": "Курсовая работа"
    }
  ]
}
```

## 5. Дизайн-система: Material 3 Expressive и 4 палитры

Приложение строится на **Material 3 Tonal Surfaces**: разделение элементов происходит не за счет черных рамок (`Border`) или тяжелых теней (`Shadow`), а за счет тональных контейнеров (`surface`, `surfaceContainerLow`, `surfaceContainer`, `surfaceContainerHigh`).

- **Шрифт:** `Onest` (или системный `Roboto Flex` / `Google Sans`).
- **Скругления:** Крупные и дружелюбные — карточки фокуса `28.dp`, кнопки и док `24.dp`, чипы `14.dp`, шторка `32.dp`.
- **Цветовые схемы (`ThemePalette` в DataStore):**
  1. `SAGE` (Шалфей — природный спокойный зеленый, по умолчанию): Primary `#356847` (Light) / `#9CD3AC` (Dark).
  2. `CLAY` (Терракота — теплая глина/песок): Primary `#8C4A27` (Light) / `#FFB690` (Dark).
  3. `LAVENDER` (Лаванда — спокойный серо-фиолетовый): Primary `#585489` (Light) / `#C2BFFF` (Dark).
  4. `OCEAN` (Океан — прохладный мятно-синий): Primary `#176678` (Light) / `#8CD0E4` (Dark).

## 6. Подробная спецификация экранов (Jetpack Compose)

В приложении **всего 2 вкладки** в нижнем `NavigationBar` (`Сейчас` и `Полки`) и **1 модальная шторка** (`ModalBottomSheet`) для сброса мыслей.

### 6.1. Экран 1: Вкладка «Сейчас» (`NowScreen.kt`)
Главный экран анти-перегруза.

1. **Top Header:**
   - Приветствие (`Привет, Данила`) + спокойный подзаголовок (`Никакой спешки. Выбери, на что есть силы:`).
   - Иконка быстрого переключения темы/палитры в правом углу.
2. **Ряд выбора состояния (`FilterChip` row из 3 элементов):**
   - `Легкое` (иконка `Spa`, соответствует `EnergyLevel.EASY`).
   - `На 5 мин` (иконка `Bolt`, соответствует `EnergyLevel.FIVE_MIN`).
   - `Поработать` (иконка `Psychology`, соответствует `EnergyLevel.FOCUS`).
3. **Центральная карточка фокуса (`FocusTaskCard`):**
   - Показывает **только одну** задачу. Анимируется через `AnimatedContent` при смене.
   - Верхняя строка: тональный бейдж `categoryBadge` + оценка времени (`3 мин`).
   - Центр: крупный текст текущего шага (`19.sp`, `SemiBold`). Если пользователь нажимал «Проще», текст берется из `simplifiedSteps`.
   - Подсказка: мягкий текст `aiHint` (`13.sp`, цвет `onSurfaceVariant`).
   - **Ряд из 3 кнопок внутри карточки:**
     - **Кнопка «Проще»** (`FilledTonalButton` с иконкой `AutoAwesome`): циклически переключает `currentSimplifyIndex` (0 -> 1 -> 2), мгновенно уменьшая масштаб задачи.
     - **Кнопка «Не сейчас»** (`FilledTonalButton` с иконкой `Refresh`): без штрафов и негатива скрывает текущую карточку и достает следующую.
     - **Кнопка «Готово»** (`Button` с иконкой `Check`): отмечает задачу выполненной (`isCompleted = true`), показывает короткую похвалу на 1.5 сек и плавно подает следующую задачу.
   - *Empty State:* если задач для выбранного фильтра нет, выводится спокойная карточка: *«На этой полке всё чисто. Можно просто отдохнуть или сбросить новые мысли»*.
4. **Нижний док Сброса (`CaptureDock` над `NavigationBar`):**
   - Расположен прямо под большим пальцем:
   - Широкая кнопка (`64.dp` высотой, `primaryContainer`): иконка микрофона + текст **«Сбросить мысли / Скажи всё подряд — ИИ разберёт»**. Нажатие открывает `CaptureBottomSheet` в голосовом режиме.
   - Квадратная кнопка справа (`64.dp x 64.dp`, `surfaceContainer`): иконка клавиатуры. Нажатие открывает `CaptureBottomSheet` сразу в текстовом режиме (для метро/лекций/ночи).

---

### 6.2. Шторка записи: «Сброс мыслей» (`CaptureBottomSheet.kt`)
Реализуется через `ModalBottomSheet`.

1. **Шапка шторки:**
   - Заголовок (`Слушаю... Говори свободно` или `Быстрый сброс текстом`) + кнопка переключения режима `Текстом / Голосом`.
2. **Режим голоса (`VoiceCaptureContent`):**
   - **Дышащая фигура M3 (`MorphingVoiceOrb`):** кастомный `Canvas` или `graphicsLayer` с плавной морфинг-анимацией скругленного многоугольника, радиус которого реагирует на амплитуду голоса (`onRmsChanged` из `SpeechRecognizer`).
   - Никаких прыгающих тегов во время речи. Только спокойный живой текст транскрибации.
   - **Детектор паузы (GTD Memory Trigger):** если пользователь молчит 3 секунды, плавно (`AnimatedVisibility`) появляется карточка-подсказка со случайным вопросом из базы триггеров:
     - *«Кому ты обещал написать или скинуть файл на этой неделе?»*
     - *«Есть ли что-то по учебе или работе, к чему страшно приступить?»*
     - *«Что нужно купить из бытовых мелочей в ближайшие дни?»*
     - *«От кого ты сейчас ждешь ответа или проверки?»*
     - По тапу на карточку вопрос меняется на следующий.
3. **Режим текста (`TextCaptureContent`):**
   - Крупное поле ввода без рамок (`TextField` в `surfaceContainer`, `20.dp` radius) с плейсхолдером: *«Пиши сплошным потоком без запятых: надо купить батарейки сделать курсач в пятницу кино...»*.
4. **Кнопки завершения:**
   - `Отмена` и `Сбросить и закрыть`.
   - При нажатии `Сбросить и закрыть`: шторка мгновенно закрывается, запускается фоновый разбор, а на главном экране всплывает `Snackbar`: *«Мысли тихо разложены по полкам»* с кнопкой перехода в `Полки`.

### 6.3. Экран 2: Вкладка «Полки» (`ShelvesScreen.kt`)
Спокойный обзор всей системы без давящих списков и счетчиков.

1. **Top Bar:**
   - Заголовок `Полки` + подзаголовок `Никаких красных дат и «просрочено»`.
   - Кнопка поиска (`Search`) для быстрого нахождения старых мыслей и кнопка настроек темы.
2. **4 тональных контейнера (`ShelfCard`):**
   - **1. Простые шаги (`SIMPLE_STEPS`):** показывает список одиночных дел с круглым чекбоксом.
   - **2. Большие дела (`BIG_THINGS`):** группирует задачи по `projectId`. **Важное правило:** для каждого проекта в карточке отображается его название (мелким акцентным шрифтом сверху) и **ТОЛЬКО ОДИН** (первый незавершенный) шаг. При клике на сам проект открывается детальная шторка проекта, где при желании можно посмотреть остальные шаги.
   - **3. Жду от других (`WAITING`):** задачи в режиме ожидания. По клику можно перевести в активные шаги или закрыть.
   - **4. На потом и отдых (`SOMEDAY`):** фильмы, идеи, хотелки и задачи, перенесенные мягкой амнистией.

## 8. Пошаговый план разработки для ИИ-агента (Implementation Roadmap)

ИИ-агент должен выполнять разработку строго по этим этапам:

- **Этап 1: Инициализация и Дизайн-система M3**
  - Настроить `build.gradle.kts` (Compose BOM, Material 3, Room, Hilt, Kotlinx.Serialization, DataStore, Material Icons Extended).
  - Реализовать `ColorPalettes.kt` с 4 тональными палитрами (`Sage`, `Clay`, `Lavender`, `Ocean`) для Light и Dark режимов и сохранением выбора в `DataStore`.
- **Этап 2: Слой данных (Room + Seed Data)**
