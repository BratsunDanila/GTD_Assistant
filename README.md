# СБРОС (Sbros) — Персональный GTD-ассистент с искусственным интеллектом

> **«Сказал и забыл»** — освобождение головы от мыслей и хаоса без сложного ручного учета, паралича перед списками и культа продуктивности.

---

## 💡 О проекте

Большинство существующих планировщиков задач требуют от пользователя роли личного секретаря: вручную набрать заголовок, выбрать проект, выставить приоритеты, настроить дату и время напоминания. При малейшем сбое привычки такие приложения начинают давить красными индикаторами просрочки и упрекающими уведомлениями, вызывая чувство вины и желание удалить приложение.

**«СБРОС»** решает проблему иначе — за счет передачи всей рутины структурирования искусственному интеллекту:

1. **Нулевой порог входа:** вы просто наговариваете или печатаете всё, что накопилось в голове, в свободной форме (с жалобами, эмоциями и разговорными оборотами).
2. **Интеллектуальный семантический разбор:** нейросетевая модель отсекает эмоциональный шум, формирует четкие заголовки с глаголом в неопределенной форме, извлекает параметры времени в 24-часовом формате (например, *«в 6 вечера»* превращается в `18:00`) и раскладывает задачи по категориям.
3. **Защита от паралича выбора:** на главном экране отображается **ровно одна задача** под текущий запас энергии, а не бесконечный пугающий список из десятков дел.
4. **Снижение планки первого шага (кнопка «Проще»):** мгновенное деление объемного дела на простое 2-минутное действие прямо на устройстве без задержек сети.
5. **Мягкая амнистия планов:** отсутствие чувства вины — отложенные дела спокойно убираются на полку идей без тревожных красных дат.

## 📱 Ключевые экраны и функции

### 1. Экран «Сейчас» (Фокус внимания)
* Отображение единственной карточки текущего дела с категорией, временем и сложностью.
* Фильтр под текущий уровень энергии: **«Мало сил»**, **«Нормально»**, **«Заряжен»**.
* Кнопка **«Проще»** — мгновенно понижает когнитивную планку задачи до элементарного действия.
* Кнопка **«Не сейчас»** — мягкий сдвиг дела в конец очереди без чувства вины.

### 2. Голосовой и текстовый сброс мыслей (Capture)
* Модуль голосового ввода на базе `SpeechRecognizer` с контроллером удержания сессии: **запись не прерывается** во время естественных пауз в речи (таймаут тишины до 2,5 с).
* Плавная визуализация звуковой волны в реальном времени, подтверждающая активность микрофона.
* Возможность переключения между диктовкой голосом и быстрым набором сплошного текста.
* Защитный алгоритм приоритета объекта: академические и ответственные задачи (курсовые, олимпиады, экзамены) гарантированно маркируются как «Сложно».

### 3. Экран «Полки» (Адаптированная методология GTD)
Вместо сложной корпоративной терминологии все входящие обязательства распределяются по 4 понятным полкам:
* **«Простые шаги»** — короткие разовые действия.
* **«Большие дела»** — составные проекты из цепочки шагов (в фокус выводится только первый незавершенный шаг).
* **«Жду ответа»** — дела, зависящие от других людей.
* **«На потом и идеи»** — планы и мысли без жестких сроков.

### 4. Экран «Календарь»
* Наглядная сетка месяца с индикаторами запланированных дел.
* Фильтрация задач по выбранной дате с отображением точного времени.

### 5. Персонализация и комфорт
* Четыре гармоничные цветовые палитры: **Шалфей (Sage)**, **Глина (Clay)**, **Лаванда (Lavender)**, **Океан (Ocean)**.
* Поддержка системной темной и светлой темы.
* Автономный режим с локальным синтаксическим парсером при отсутствии подключения к сети.
* Опциональная облачная синхронизация через Supabase.

## 🧪 Тестирование

Проект покрыт пакетом автоматических тестов (`app/src/test/`):
* **Парсер времени:** проверка конвертации вечерних часов в 24-часовой формат (например, «6 вечера» $\to$ `18:00`), расчет относительных дат («сегодня», «завтра», «послезавтра»).
* **Очистка заголовков:** проверка корректного удаления временных маркеров и междометий из результирующего названия задачи.
* **Классификатор сложности:** проверка принудительного присвоения статуса «Сложно» крупным учебным и проектным делам.
* **Логика фокуса:** проверка изоляции первого шага проекта и фильтрации задач по уровням энергии.
* **Целостность базы данных:** проверка каскадного удаления шагов при удалении проекта в Room.

## 🚀 Сборка и запуск

1. **Требования:**
   * Android Studio (Koala / Jellyfish / Iguana или новее)
   * JDK 17
   * Android SDK (compileSdk 34, minSdk 26)

2. **Клонирование репозитория:**
   ```bash
   git clone https://github.com/BratsunDanila/GTD_Assistant.git
   cd GTD_Assistant
   ```

3. **Сборка APK:**
   ```bash
   ./gradlew assembleDebug
   ```

4. **Запуск тестов:**
   ```bash
   ./gradlew test
   ```
